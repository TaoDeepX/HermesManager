# HermesManager 使用说明

本文档面向首次使用 **HermesManager** 的小白用户，介绍从下载到完成 HermesAgent 安装的完整流程。

## 一、它是什么

HermesManager 是 [HermesAgent](https://github.com/NousResearch/hermes-agent) 的图形化一键安装器，全程**零命令行**、**中文界面**、内置**国内镜像加速**，让没接触过开发环境的小白也能在 10 分钟内把 HermesAgent 跑起来。

## 二、系统要求

| 系统 | 最低版本 | 备注 |
|---|---|---|
| Windows | 10 / 11（x64） | 需开启 CPU 虚拟化（VT-x / AMD-V） |
| macOS | 12 Monterey 及以上 | 支持 Intel 与 Apple Silicon |

> 还需要：稳定网络（国内用户**无需科学上网**，内置清华 / ghproxy / npmmirror 镜像）。

## 三、安装步骤

### 1. 下载安装包

前往 [Releases 页面](https://github.com/TaoDeepX/HermesManager/releases) 选择对应平台：

- **Windows**：`HermesManager-Setup-x.y.z-x64.msi`
- **macOS**：`HermesManager-x.y.z-universal.dmg`

### 2. 安装并启动

- **Windows**：双击 `.msi`，按向导完成安装；从开始菜单搜索 `HermesManager` 打开。
- **macOS**：双击 `.dmg`，将 `HermesManager.app` 拖到 `Applications`；首次打开如遇"无法验证开发者"，请到"系统设置 → 隐私与安全性"放行。

### 3. 一键体检

点击主界面的 **「开始体检」** 按钮，程序会自动检测：

- 系统版本与 CPU 架构
- CPU 虚拟化是否开启（Windows）
- WSL2 / Ubuntu 是否已安装（Windows）
- Homebrew 是否已安装（macOS）
- Node.js、Rust、Python 等依赖
- 网络连通性与镜像可达性

检测完成后，未通过的项目会显示 **「一键修复」** 按钮，点击即可自动安装或配置。

### 4. 选择模型提供商

进入「模型」页，从内置的 **15+ 提供商卡片**中选一个：

| 推荐场景 | 提供商 | 特点 |
|---|---|---|
| 国内新手首选 | 阿里百炼 DashScope | 注册即送额度，无需付费 |
| 高性价比 | DeepSeek / Kimi | 价格低、中文好 |
| 顶级效果 | Claude / OpenAI / Gemini | 需海外信用卡或代充 |
| 完全本地 | Ollama | 离线运行，不联网 |

点击卡片上的「获取 Key」会直接跳转到该提供商的控制台，按指引申请 API Key 后填入即可。

### 5. 测试连接

填好 API Key 后点 **「测试连接」**，看到绿色 ✅ 即代表配置成功。

### 6. 等待自动安装

点击 **「开始安装」**，HermesManager 会在后台执行：

1. 下载 HermesAgent 源码（走镜像加速）
2. 创建 Python 虚拟环境
3. 安装依赖
4. 写入用户配置（API Key、模型偏好等）
5. 注册全局 `hermes` 命令

整个过程约 **3–10 分钟**，视网速而定，主界面会显示实时进度条与日志。

### 7. 开始使用

安装完成后，有两种使用方式：

- **终端使用**：在 WSL（Windows）或 macOS 终端中输入 `hermes`，即可开始对话。
- **IM 使用**：在「集成」页勾选微信 / Telegram / Discord / Slack / WhatsApp 等网关，按提示扫码登录即可在手机上随时聊。

## 四、常见问题

### Q1: Windows 提示"虚拟化未开启"

进入主板 BIOS / UEFI（开机按 Del / F2 / F10），找到 `Intel VT-x` 或 `AMD-V / SVM`，启用后保存重启。

### Q2: macOS 安装 Homebrew 卡住

HermesManager 默认使用清华镜像源，如果仍然卡顿，可在「设置 → 镜像」切换为中科大或阿里镜像。

### Q3: API Key 测试失败

- 确认 Key 没有多余空格或换行
- 确认账户额度未用完
- 部分海外提供商需要"科学上网"才能直连，可在「设置 → 代理」填入本地代理地址

### Q4: 如何卸载

- **Windows**：控制面板 → 程序与功能 → 找到 HermesManager → 卸载
- **macOS**：将 `HermesManager.app` 拖入废纸篓
- 如需同时移除 HermesAgent 本体，在主界面点 **「设置 → 完全卸载」**
